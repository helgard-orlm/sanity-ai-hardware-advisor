Questions to try

Each Copy puts this line in front of the question: "Use the AI Hardware Advisor tools: call initial_context first…". Without it, an agent may answer from memory and skip the base. Agent files: setup.md · SKILL.md (Claude Code and Codex skill) · llms.txt.

What happens when you ask

1Instructions + schemainitial_context gives the agent the advisor's work order and the dataset schema through Sanity Context MCP.
2Need in numbersLaws (weights, KV cache, speed ceiling, own vs rent) are fetched as data with groq_query. Models that are not in the base are looked up on the web, using the base's rules as a checklist.
3Every pathAll 11 solution paths, from keeping what you have to renting a GPU, get a yes, no or maybe with a number.
4Math checkedcheck_answer recomputes each calculation with the formula stored in Sanity and returns errors until the answer is right.

Tools on this server

initial_contextAdvisor instructions plus the Sanity schema and document counts. Call it first.
groq_queryRead-only GROQ over the public dataset v2, with embeddings on, so semantic search works.
schema_explorerFields and allowed values of one document type.
array_field_readerReads long array fields in parts.
check_answerThe validator from the app. It recomputes laws, checks that every path got a verdict, catches substitute products and flags prices without a source. Added by this server.

The first four tools are Sanity Context MCP, passed through unchanged. The access token stays on the server.

Limits and privacy

This is a free demo on a free Sanity plan, so calls are limited per visitor per hour and per day in total. Past the daily limit, groq_query falls back to the public dataset API. The server logs which tool was called and the GROQ query text, with a salted hash in place of your IP address. It never sees your chat. Answers are advice from a knowledge base, not a guarantee.
